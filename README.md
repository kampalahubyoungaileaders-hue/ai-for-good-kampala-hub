# AI for Good Kampala Hub

Official web project for the AI for Good Young AI Leaders Community — Kampala Hub.

## Purpose

The site supports the Kampala Hub's mission to grow local AI talent, promote responsible AI, and help grassroots innovators apply AI to challenges that matter in Uganda while contributing to the Sustainable Development Goals.

## Stack

- Static HTML/CSS/JavaScript frontend
- Supabase for member, event and insight content
- Netlify-ready deployment configuration

## Supabase

Project: `ai-for-good-kampala-hub`

Public content tables:
- `members`
- `events`
- `insights`

All exposed tables use Row Level Security. The browser uses only a Supabase publishable key.

## Content principles

- Do not display a fixed member count as a headline; membership changes over time.
- Workshop/event attendees must not be presented as Hub members unless they are verified members.
- Use photos sparingly and only where their context is clear.
- Keep the Hub connected visually and editorially to AI for Good while retaining a distinct Kampala identity.
- Emphasize grassroots innovation, talent development, responsible AI, and contribution to the SDGs.
