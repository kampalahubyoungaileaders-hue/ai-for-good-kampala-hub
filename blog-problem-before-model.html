Grassroots innovation

Start with the problem, not the model.

Useful AI starts with people, evidence and a problem worth solving.

It is easy to begin with a model and then search for somewhere to use it. Grassroots innovation works in the opposite direction. Start with the people affected, understand the friction they face, gather evidence and only then ask whether AI can add value.

This matters because many local problems are not primarily prediction problems. Sometimes the real bottleneck is missing information, poor processes, weak coordination or lack of access. AI may help, but it should earn its place in the solution.

A strong Kampala Hub project should be able to explain the problem in plain language, identify who benefits, describe what data is needed, name the risks and define what success would look like before choosing a model.
